# GR12-Culminating

A responsive web application built in **June 2025** that lets users browse Pokémon cards, view details, and explore a custom card database. Designed with a clean UI, intuitive navigation, and modular components for easy expansion.

## 🚀 Features
- **Dynamic Card Browser:** Displays cards from a local JSON dataset.
- **Card Details View:** Shows stats, types, HP, attacks, and card imagery.
- **Search & Filters:** Find cards by name, type, or set.
- **Modern UI:** Built with custom styling, smooth animations, and a responsive layout.
- **React Routing:** Navigation between Home, Map, Card Pages, and Settings.
- **Reusable Component Structure:** Cards, modals, navigation bar, data utilities, and more.

## 🛠️ Tech Stack
- **React + Vite**
- **TypeScript**
- **React Router**
- **CSS / Tailwind / Custom Styles**
- **Local JSON Data**

- ## 🎯 Purpose
This project was built to improve my skills in:
- Front-end architecture (React + TypeScript)
- UI/UX design
- Data-driven rendering
- Component reusability
- Routing and state management
